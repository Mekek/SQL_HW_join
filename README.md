# Анализ заказов маркетплейса в PostgreSQL

Проект исследует клиентов, заказы, сроки доставки, отмены, категории товаров и выручку. Он создан во время курса по Go и SQL в техношколе Wildberries; курс пройден полностью. После обучения запросы объединены в воспроизводимый проект и очищены от локальных путей.

## Что показано

- проектирование таблиц и связей через внешние ключи;
- `JOIN`, группировки и условные агрегаты;
- CTE и оконное ранжирование;
- поиск задержек, отмен и лидеров продаж;
- загрузка исходных CSV через `psql`.

## Запуск

Нужен PostgreSQL и клиент `psql`. Выполняйте команды из корня проекта:

```bash
createdb marketplace_orders
psql -d marketplace_orders -f schema.sql
psql -d marketplace_orders -f analysis.sql
```

`schema.sql` пересоздаёт таблицы, поэтому проект можно запускать повторно.

## Структура

```text
data/          небольшие исходные выборки
schema.sql     таблицы, ограничения и загрузка данных
analysis.sql   аналитические запросы
```

## Стек

PostgreSQL, SQL, JOIN, CTE, агрегатные и оконные функции.
